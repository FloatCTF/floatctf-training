## 视觉方向

默认浅色主题采用编辑出版物风格。页面使用暖白纸张背景、墨色正文、低饱和红色强调、细分隔线和宽留白。视觉层级由字号、字体、线条和间距建立，阴影只用于区分浮层或可交互表面。

首页按课程目录设计。专题页按技术教材设计。两类页面共享字体、颜色 token、边框语言和状态语义。

深色主题服务于投屏和安全演示。打印主题服务于纸张和 PDF。用户显式选择主题后保持选择结果。

## 字体与排版

标题使用 Noto Serif SC，正文使用 Noto Sans SC，代码和微型标签使用 JetBrains Mono。字体通过本地文件或构建依赖打包，页面运行时不请求字体 CDN。

正文权重、加粗权重、行高和正文栏宽以 `training-policy.json` 为准。展示标题使用紧凑行高，正文保持短段落和稳定阅读宽度。

排版职责如下：

- 大标题建立页面主题。
- 衬线小标题划分课程结构。
- 等宽英文标签表达课程编号、版本、状态和统计。
- 正文解释机制、证据和操作。
- 行内代码使用高对比底色、边框和等宽字体。

术语高亮使用实色背景。页面避免透明渐变文字、超细中文字体和运行时外部字体。

## Token 与主题

颜色、间距、圆角、阴影、字体、层级和动效时间使用变量。`config/themes.json` 是颜色的唯一权威来源，`scripts/generate-theme-css.mjs` 将其生成到 `src/styles/generated-themes.css`。

浅色主题至少提供：

- 暖白页面背景和浅纸张表面。
- 墨色正文与标题。
- 低饱和红色强调和链接。
- 可达到 UI 对比度要求的边框与焦点环。
- 黄色信息区、红色危险区和绿色正确区。
- 深色代码背景与浅色代码文字。
- 表头背景、表头文字与斑马纹使用独立 token，并逐主题验证对比度。

主题切换只改变 token。教学正文、lesson manifest 和 catalog 保持独立。

## 页面壳层与样式分层

页面 frontmatter 使用 `pageType` 区分 `home`、`category` 和 `lesson`。`training-page-frame.astro` 根据页面类型控制侧栏与正文宽度：首页、分类页和专题页使用无侧栏壳层，普通文档页保留 Starlight 全局导航。

`training-header.astro` 统一提供品牌、搜索和主题切换。专题页把课程路径、当前专题和本课目录合并进同一顶栏，避免叠加第二条固定导航。手机端压缩品牌与工具区，保留返回、当前课名、目录、搜索和主题切换。

样式按职责拆分：`base.css` 定义基础排版，`shell.css` 定义站点壳层与顶栏，`home.css`、`category.css`、`lesson.css` 定义页面结构，`components.css` 定义教学组件，`responsive.css` 与 `print.css` 定义媒介规则。`global.css` 只加载字体、生成主题和这些模块。新增规则进入对应文件，禁止在文件尾追加第二套覆盖系统。

## 导航站首页

首页使用 `template: splash` 和 catalog 驱动的目录组件。结构依次为：

1. 等宽英文眉题。
2. 居中的中文主标题。
3. 说明课程内容和安全范围的短副标题。
4. 横向墨色分隔线。
5. 双栏分类目录。
6. 授权范围、分类数、专题数和可进入数量。

分类目录由 `LearningMap` 渲染。每个分类卡显示罗马数字、分类名、简介、专题总数和可进入数量。首页分类卡**不内联展开**专题列表，避免某一类条目过多时撑破双栏网格。

首页点击分类卡时，打开 `role="dialog"` 面板展示该分类的专题列表。面板内容依次为：罗马数字、分类名、简介、统计、专题行、底部「查看完整分类说明」链接。已完成专题使用链接、难度和方向箭头。规划专题使用普通文本、难度和“规划中”状态，保持 `aria-disabled`，禁止产生空页面链接。

分类卡本身是指向分类页的真实链接。有 JavaScript 时拦截点击并打开面板；无 JavaScript 时正常进入分类页。关闭面板支持 Esc、遮罩点击和关闭按钮；打开期间锁定背景滚动、陷阱焦点，并在关闭后把焦点退回触发卡。桌面使用居中面板；窄屏使用底部 sheet。面板动效遵循 [motion-system.md](motion-system.md)，须响应 `prefers-reduced-motion`。

桌面使用双栏分类卡。手机回落为单栏。分类卡网格在任意交互下保持等高稳定，禁止再用首页 `<details>` 内联展开专题。

首页首屏在常见桌面视口中同时露出第一排分类。大标题用于建立站点识别，课程入口保持在首屏任务路径中。罗马数字列禁止拆行，`VII`、`VIII` 等较长编号保持完整。

## 分类页

分类页使用无侧栏课程目录结构。页面顶部依次显示返回课程地图的路径、罗马数字、分类眉题、分类名和简介；正文直接呈现分类说明与单栏专题目录。

分类页复用 `LearningMap` 的专题行和状态语义，以静态列表（`category-directory-static`）直接展示当前分类专题，**不使用**首页弹层。当前分类卡不再生成指向自身的“查看分类说明”链接。已完成专题提供链接，规划专题保持不可点击。分类页与首页共享 catalog 数据，禁止另建导航数据副本。

## 专题页刊头与章节

专题深度页使用技术教材与课程海报结合的结构。统一顶栏内的课程路径与可展开本课目录承担导航，在正文版心内建立以下层级：

1. 等宽课程系列、单元编号和英文主题名。
2. 按标题语义分行的衬线展示标题，其中一行使用强调色。
3. 一段说明学习路径的短摘要。
4. 并排的学习目标与前置知识。
5. 带序号、粗分隔线和宽留白的正文章节。

`LessonHero` 接收系列、单元、眉题、标题行和摘要。组件只提供结构，具体专题文案由 MDX 传入。页面保留一个仅供语义和辅助技术使用的 `h1`，展示标题作为视觉表达，避免重复标题层级。

展示标题根据内容长度使用短、中、长三档字号。中文按语义行拆分，英文词组保持词内完整，禁止使用 `overflow-wrap: anywhere` 拆开单词。SSRF、深度学习和 Git 示例覆盖三种标题长度。

参考既有网页、截图或设计稿时，先提取色彩关系、字体层级、边框强度、留白节奏和组件状态，再映射到站点 token 与通用组件。保留站点导航、内容 schema、无障碍语义和降级行为。参考页面中的具体文案、布局尺寸和实现代码不直接复制。

章节序号由样式计数器生成。正文只保留语义标题，增加或移动章节时无需手工重编号。手机缩小展示标题并改为单列；打印取消视口高度，保留标题、摘要和章节序号。

已完成的专题页在 frontmatter 设置 `pageType: lesson` 和 `template: splash`。`training-header.astro` 通过 `lesson-navigation.astro` 渲染返回课程地图、当前分类、当前专题和原生 `details` 本课目录；`training-page-title.astro` 只保留语义标题。课程路径来自 catalog，目录来自页面的二级与三级标题。

Lesson plan 的受众、时长、教学模式、证据档案、考核、动效等级与核验日期用于生成和质量门禁，默认不进入读者页面。需要展示版本、环境或安全范围时，把它们放在对应正文小节中并说明实际用途。

## 专题页组件

组件接收内容数据与视觉变体，不硬编码具体专题文案。Starter 提供：

- 学习目标框与前置知识框。
- 直觉解释框。
- 信息、警告、危险和正确提示框。
- 深色代码块。
- 脆弱代码与正确代码并排对照。
- 数据表格。
- 重点结论卡。
- 四档面试手风琴。
- 速查卡。
- 来源列表。
- 按需信息栏，只接收页面显式提供的标签和值。
- 安全免责声明。
- 规划中专题卡片。
- 响应式分类学习地图。
- 结构化专题刊头。

专题组件使用墨色外框和语义色左边框。代码块保持深色 IDE 风格。表格使用反色表头和交替行底色。重点结论使用衬线排版和强调色左边框。

组件标题通过 props 传入，默认值只表达组件类型。数据表格提供 caption、表头作用域和横向滚动容器。提示框同时使用标题、边框和文字表达状态。

## 布局与响应式

正文保持可读栏宽，宽屏增加留白。首页目录使用更宽的独立容器。学习地图、代码对照和按需信息栏使用自适应网格。

窄屏使用单列，代码和数据表保留容器内滚动，页面主体禁止产生横向溢出。分类摘要、按需信息和状态文字在窄屏允许换行。

链接、按钮、原生 details 和 range 控件保持可见焦点。点击目标尺寸和响应式断点从 `training-policy.json` 读取。

## 打印

打印主题显示完整正文、面试答案、时间轴静态步骤和目录内容。打印时隐藏交互控件与站点导航，保留分类标题、专题状态和来源 URL。

代码允许换行和分页。提示框、分类目录和表格尽量避免跨页截断。打印颜色由 `themes.json` 提供。

## 设计验证

结构门禁根据 `training-policy.json` 中的 WCAG 阈值计算三套主题的相对亮度和对比度。

当前环境有浏览器能力时，验证以下项目：

- 桌面浅色首页和专题页。
- 桌面深色专题页。
- 首页首屏可看到课程入口，双栏编号和卡片顶线对齐。
- 分类页无左右侧栏、自引用链接和重复导航。
- 专题页只有一层主要顶栏，课程路径与本课目录可用。
- 短、中、长标题在桌面与手机上保持词组完整。
- 手机单栏目录和横向溢出。
- 分类目录开合和键盘操作。
- 规划专题的无链接状态。
- 打印、减少动态和无 JavaScript 状态。
- 焦点可见性、内部链接和控制台错误。

颜色修复只修改 `themes.json` 并重新生成 CSS。目录内容只修改 catalog。视觉结构只修改组件和样式。
