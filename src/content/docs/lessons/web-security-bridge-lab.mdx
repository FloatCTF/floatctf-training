## 引导问题：不靠现成扫描器，光凭基础工具能解决多少问题

不少初学者以为做安全得先装满几十个大工具。真进靶场或读陌生代码库就会发现，日常最常用的依然是五项基本功：筛日志找线索、拆解 HTTP 与凭据、写十几行小脚本翻页汇总，以及读懂基础汇编。

下面这张交互任务看板把五关的目标、关键命令和核对信号收在了一起——在自己终端每跑通一关，可以勾选记录进度：
