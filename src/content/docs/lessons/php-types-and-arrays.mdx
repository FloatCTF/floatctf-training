## 引导问题："5" 加 3 等于几

上一课说过，`$_GET` 里取出来的值永远是字符串。用户在网址里写 `?count=5`，PHP 拿到的是 `"5"`。

如果你接着写 `$_GET['count'] + 3`，会发生什么？Python 会报 `TypeError`，因为字符串和数字不能相加。C 根本不让你这样写。PHP 会给你一个答案。

这个答案是什么、PHP 是怎么得出的，就是这一课的主题。网站的输入全是字符串，而程序拿它们去算、去比较，所以这些规则每天都在起作用。

## 二、两个等号和三个等号

### 1. 先转换再比，还是连类型一起比

<CodeFile file="labs/php-types-and-arrays/compare.php" />

<TerminalSession
  title="八组比较"
  steps={[
    { cmd: 'php compare.php', out: 'bool(true)\nbool(false)\nbool(true)\nbool(false)\nbool(true)\nbool(true)\nbool(false)\nbool(false)' },
  ]}
/>

<DataTable
  caption="compare.php 的八行"
  headers={["比较", "结果", "说明"]}
  rows={[
    ["1 == \"1\"", "true", "== 先做类型转换再比"],
    ["1 === \"1\"", "false", "=== 不转换：一个是 int，一个是 string"],
    ["\"10\" == \"1e1\"", "true", "两边都是数字形式的字符串，按数值比。1e1 是科学计数法，等于 10"],
    ["\"10\" === \"1e1\"", "false", "两个不同的字符串"],
    ["100 == \"1e2\"", "true", "同理，1e2 是 100"],
    ["null == false", "true", "两者转成布尔值都是假"],
    ["0 == \"a\"", "false", "\"a\" 不是数字，PHP 8 把 0 转成 \"0\" 再按字符串比"],
    ["\"abc\" == 0", "false", "同上"],
  ]}
  columnRatios={[1.1, 0.6, 3.2]}
/>

（来源：[Comparison Operators](#source-php-comparison)）

<Callout variant="warning" title="旧教程里的结论可能是错的">
最后两行在 PHP 7 及更早的版本里结果是 **true**：那时字符串和数字比较，会先把字符串转成数字，`"a"` 变成 0。PHP 8 改掉了这条规则。网上很多文章和老项目是按旧规则写的，读的时候先看清它说的是哪个版本。
</Callout>

两个等号的结果取决于一套转换规则，而且这套规则还在不同版本间变过。三个等号只有一条规则：类型和值都相同。**写程序时默认用 `===` 和 `!==`，只在确实需要转换时才用 `==`。**

<TerminalSession

### 1. 两种用法

Python 有列表和字典两种东西，PHP 只有一种：**数组**。它本质上是一个有序的「键 → 值」映射，键可以是整数也可以是字符串。

<KeyTakeaway>
PHP 的值有类型，但运算符会自动转换它：加号把操作数当数字，点号当字符串；完全不是数字的字符串参与算术时，PHP 8 会抛出 TypeError。`==` 先转换再比较，规则复杂而且在 PHP 8 改过；`===` 要求类型和值都相同，应当默认使用，`in_array` 也要加上第三个参数 `true`。PHP 的数组是有序的键值映射，同时承担列表和字典的角色。
</KeyTakeaway>
