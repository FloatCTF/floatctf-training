## 引导问题：密码输错三次会怎样

登录页面都有这样的规则：密码对了就放行，错了提示还剩几次，连错三次就锁定。

用上一课学的东西写不出这个规则，因为它需要两种新能力。一是**判断**：密码对不对。二是**重复**：没输对就再问一次，最多问三次。这一课结束时，你会用十一行代码把它写出来。

读这段代码的规则：

- 从上往下依次检查条件，**遇到第一个成立的就执行它下面那一块**，剩下的分支全部跳过。
- `elif` 是 else if 的缩写，可以有任意多个；`else` 兜底，可以没有。
- 每个条件后面有一个冒号 `:`。

（来源：[More Control Flow Tools](#source-py-controlflow)）

### 3. 缩进就是语法

`print("too short")` 前面的四个空格不是为了好看。Python 用**缩进**表示「这几行属于上面那个 if」：缩进相同的连续几行是一个代码块。（来源：[An Informal Introduction to Python](#source-py-introduction)）

```text
if 条件:
    这一行属于 if        ← 缩进 4 个空格
    这一行也属于 if
这一行不属于 if，无论条件是否成立都会执行
```

约定是每一级缩进 4 个空格，直接敲四下空格最稳妥。同一个文件里不要混用 Tab 和空格，混用会报 TabError。

## 二、while、for 与 break

### 1. while：条件成立就再来一遍

<CodeFile file="labs/python-control-flow/countdown.py" />

<TerminalSession
  title="倒数"
  steps={[
    { cmd: 'python3 countdown.py', out: '3\n2\n1\ngo' },
  ]}
/>

`while` 的执行顺序是：检查条件，成立就把循环体从头到尾执行一遍，然后**回到 while 那一行重新检查条件**；不成立就跳到循环体后面继续。这里 n 每一圈减 1，减到 0 时条件 `n > 0` 不成立，循环结束。

循环体里必须有让条件最终变成不成立的语句。漏掉 `n = n - 1`，这个循环永远停不下来。

### 3. break：提前结束循环

现在可以写开头那个登录规则了：

<CodeFile file="labs/python-control-flow/login.py" />

<TerminalSession
  title="第二次输对，以及连错三次"
  steps={[
    {
      cmd: 'python3 login.py',
      stdin: ['123456', 'kali123'],
      out: 'password: 123456\nwrong, 2 left\npassword: kali123\nwelcome',
      note: '第二次输对，执行到 break，循环立刻结束。此时 tries 是 1，最后的 if 不成立。',
    },
    {
      cmd: 'python3 login.py',
      stdin: ['a', 'b', 'c'],
      out: 'password: a\nwrong, 2 left\npassword: b\nwrong, 1 left\npassword: c\nwrong, 0 left\nlocked',
      note: '三次都错，tries 加到 3，条件 tries < 3 不成立，循环正常结束，然后打印 locked。',
    },
  ]}
/>

这段代码里 if 套在 while 里面，缩进有两级。读的时候用缩进对齐来判断归属：`print("welcome")` 和 `break` 缩进 8 个空格，属于 if；`tries = tries + 1` 缩进 4 个空格，属于 while 但不属于 if。

`break` 的作用是跳出它所在的那个循环。输对密码之后不该再执行「次数加 1」和「打印还剩几次」，所以直接 break。

<Callout variant="warning" title="密码写在代码里">
这个脚本把正确的密码直接写在了源码第一行，任何拿到文件的人都能看到。它只用来练习循环。真实的系统不会这样保存密码，后面的课会讲到。
</Callout>

<KeyTakeaway>
程序默认从上往下一行执行一次。`if` 让它按条件跳过一些行，`while` 和 `for` 让它回头重复一些行。哪些行受它们管，由缩进决定。读循环代码的方法是逐行推演：每一圈先看条件，再把循环体从头走到尾，记下每个变量的新值。
</KeyTakeaway>
