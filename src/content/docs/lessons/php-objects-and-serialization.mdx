## 引导问题：会话里存的东西，到底长什么样

第 29 课的登录页把用户名存进了 `$_SESSION`，下一次请求时它又回来了。中间这段时间，它待在服务器上的一个文件里。

文件只能存字节，`$_SESSION` 却是一个 PHP 数组，里面还可能有对象。PHP 一定有办法把这些值变成一串字符写进去，再原样读回来。这一课先学写类和对象，再看这个「变成字符串」的过程，以及它为什么只能用在你自己信得过的数据上。

## 二、对象是怎样被传来传去的

### 1. 赋值不复制对象

<CodeFile file="labs/php-objects-and-serialization/same.php" mark="5,9" />

<TerminalSession
  title="两个变量，一个对象"
  steps={[
    { cmd: 'php same.php', out: 'carol (level 2)\ncarol (level 2) / carol (level 3)', note: '第一行：通过 $b 升级，$a 也变了。第二行：clone 之后，两者各走各的。' },
  ]}
/>

变量里存的不是对象本身，而是一个指向对象的标识符。`$b = $a` 复制的是这个标识符，两个变量指向同一个对象。这和第 23 课 C 的指针很像：两个指针指着同一块内存，从哪一个改，另一个都看得到。要一个真正独立的副本，用 `clone`。（来源：[Objects and references](#source-php-oop-references)、[Object Cloning](#source-php-oop-cloning)）

数组不是这样：第 28 课的数组赋值会得到一份独立的副本。

### 2. PHP 自动调用的方法

<CodeFile file="labs/php-objects-and-serialization/lifetime.php" />

<TerminalSession

代码里从来没有写过 `$v->__destruct()`，它是被 PHP 在对象不再被使用时自动调用的。魔术方法的共同点就在这里：**你只写方法，什么时候调用由 PHP 决定**。`__construct` 在 `new` 时，`__destruct` 在对象被销毁时，`__toString` 在对象被当作字符串时。手册里还有好几个，各自对应一种时刻。（来源：[Constructors and Destructors](#source-php-oop-construct)、[Magic Methods](#source-php-oop-magic)）

## 三、把对象存成字符串

### 1. serialize 的格式

<CodeFile file="labs/php-objects-and-serialization/serialize.php" />

<TerminalSession
  title="数组和对象变成字符串，再变回来"
  steps={[
    {
      cmd: 'php serialize.php',
      out: 'a:3:{s:4:"port";i:80;s:5:"tools";a:2:{i:0;s:4:"curl";i:1;s:2:"nc";}s:4:"open";b:1;}\nbool(true)\n61 bytes\nO:4:"User":2:{s:4:"name";s:5:"alice";s:11:"\\0User\\0level";i:2;}\nalice (level 2)\nbool(false)\nbool(true)',
      note: '还原出来的对象和原来的相等（==），但不是同一个（===），是新造出来的。',
    },
  ]}
/>

`serialize` 把一个值变成可以存储的字符串，保留它的类型和结构；`unserialize` 把字符串变回原来的值。（来源：[serialize](#source-php-serialize)）

读一下对象那一行：

<DataTable
  caption={'O:4:"User":2:{…} 拆开看'}
  headers={["这一段", "含义"]}
  rows={[
    ["O:4:\"User\"", "一个对象（O），类名有 4 个字符，是 User"],
    [":2:", "有 2 个属性"],
    ["s:4:\"name\";s:5:\"alice\";", "属性名是长度为 4 的字符串 name，值是长度为 5 的字符串 alice"],
    ["s:11:\"\\0User\\0level\";i:2;", "private 属性的名字前面带着类名，两侧是两个空字节（终端里看不见，这里显示成 \\0），值是整数 2"],
  ]}
  columnRatios={[1.6, 3.2]}
/>

数组那一行同理：`a:3` 是三个元素的数组，`i:80` 是整数，`b:1` 是布尔值真。

第 29 课的会话数据就是这样存的：PHP 在脚本结束时把 `$_SESSION` 序列化，写进会话文件。（来源：[Sessions: Basic usage](#source-php-session-basic)）

### 2. 为什么不能用在外部数据上

注意 `O:4:"User"`：**字符串里写着要造出哪个类的对象。** `unserialize` 读到它，就真的造出一个 User，按字符串里写的值设置它的属性；如果这个类定义了特定的魔术方法，还会被自动调用。

如果这串字符来自你自己的会话文件，没有问题。如果它来自请求，比如 Cookie 或表单，那么「造出什么对象、属性是什么值」就由发请求的人决定了。

<Callout variant="danger" title="PHP 手册的原话">
不要把不可信的用户输入交给 `unserialize()`。反序列化可能因为对象的创建和自动加载，导致代码被加载和执行，恶意用户可能利用这一点。需要和用户之间传递数据时，用 JSON 这样安全、标准的格式（`json_encode` 和 `json_decode`）。
</Callout>

（来源：[unserialize](#source-php-unserialize)）

这类问题叫反序列化漏洞，是下学期的一个专题。现在只需要记住规矩：**`unserialize` 只用于你自己写入、别人改不了的数据；和外部交换数据一律用 JSON。**

### 3. JSON：只有数据

<CodeFile file="labs/php-objects-and-serialization/json.php" />

<TerminalSession
  title="同样的数组，换成 JSON"
  steps={[
    { cmd: 'php json.php', out: '{"port":80,"tools":["curl","nc"],"open":true}\nbool(true)\n{"name":"alice"}', note: '第 15 课 Python 的 requests 和第 17 课浏览器的 fetch 读的都是这种格式。对象只输出了 public 的 name。' },
  ]}
/>

JSON 只能表示对象（键值对）、数组、字符串、数字、真假和 null。`json_decode` 不会造出任何类的对象，第二个参数传 `true` 时得到的是普通的关联数组。这正是它适合跟外部交换数据的原因：**解码的结果只是数据，不会是带着行为的对象。**（来源：[json_encode](#source-php-json-encode)、[json_decode](#source-php-json-decode)）

<KeyTakeaway>
类把数据和操作数据的方法放在一起，`private` 让属性只能按类规定的方式改变。变量里存的是指向对象的标识符，赋值后两个变量指向同一个对象，要副本用 `clone`。魔术方法由 PHP 在特定时刻自动调用。`serialize` 把值连同类型变成字符串，`unserialize` 按字符串里写的类名把对象造回来，所以只能用在自己写入、别人改不了的数据上；和外部交换数据一律用 JSON。
</KeyTakeaway>
