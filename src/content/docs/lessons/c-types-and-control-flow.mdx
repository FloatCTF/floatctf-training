## 引导问题：一个整数能有多大

在 Python 里算 `2 ** 100`，得到一个 31 位的数，没有任何问题。Python 的整数需要多少空间就占多少空间。

C 不是这样。在 C 里声明一个整数，要先说清楚它是哪一种，而每一种的大小是固定的。超出了它装得下的范围会怎样？

这个问题不是抬杠。「装不下」是真实程序里一类错误的来源，下学期会专门讲。今天先把它的原理看明白。

## 一、类型：每个变量占固定大小

### 1. 声明变量要写类型

C 的变量在使用之前必须先**声明**，声明时写出它的类型，之后类型不能再变。（来源：[Beej's Guide: Variables and Statements](#source-beej-variables)）

```c
int count = 3;
```

`int` 是类型，`count` 是名字，`3` 是初始值。Python 里写 `count = 3` 就行，类型由值决定；C 里类型由你决定，并且决定了这个变量占多少内存。

### 3. 整数运算的两个特点

<CodeFile file="labs/c-types-and-control-flow/arith.c" />

<TerminalSession
  title="除法，以及字符就是数字"
  steps={[
    { cmd: 'gcc -Wall arith.c -o arith' },
    { cmd: './arith', out: '3\n1\n3.500000\nA 65\nB 66', note: '对照源码看：7 / 2 是 3，不是 3.5；7 % 2 是余数 1；写成 7.0 / 2 才是小数除法。' },
  ]}
/>

- **整数除以整数，结果还是整数**，小数部分直接丢掉。Python 的 `/` 会给出 3.5，C 的 `/` 相当于 Python 的 `//`。只要有一边是小数，结果才是小数。
- **`char` 里存的是数字**。`'A'` 就是 65，这是第 4 课学的 ASCII 码。所以 `c + 1` 是合法的，得到 66，按 `%c` 打印出来是 `B`。单引号括起来的是一个字符，双引号括起来的是字符串，两者不能混用。

（来源：[N1570](#source-n1570)）

## 二、装不下的时候

### 1. 无符号整数：绕回去

<CodeFile file="labs/c-types-and-control-flow/wrap.c" mark="6,9,14" />

<TerminalSession
  title="超出范围之后"
  steps={[
    {
      cmd: 'gcc wrap.c -o wrap',
      out: 'wrap.c: In function ‘main’:\nwrap.c:9:25: warning: unsigned conversion from ‘int’ to ‘unsigned char’ changes value from ‘300’ to ‘44’ [-Woverflow]\n    9 |     unsigned char cut = 300;\n      |                         ^~~',
      note: '编译器发现第 9 行想把 300 塞进一个字节，直接告诉你它会变成 44。',
    },
    { cmd: './wrap', out: '0\n44\n4294967295\n0\n2147483647', note: '255 加 1 得 0；300 变成 44；unsigned int 的最大值加 1 也得 0。最后一行是 int 的最大值。' },
  ]}
/>

`unsigned char` 只有 8 个二进制位。255 是八个 1，再加 1 需要第九位，可是没有地方放，留下的八位全是 0。300 的二进制有九位，砍掉最高位剩下 44。

规律是：**无符号整数超出范围时，结果是对「最大值加 1」取余。** 300 对 256 取余是 44。这是 C 标准明确规定的行为，可以依赖。（来源：[N1570](#source-n1570)）

### 2. 有符号整数：不要指望任何结果

`int` 这类有符号整数超出范围，标准的说法是**未定义行为**：标准不规定会发生什么，编译器可以按任何方式处理。在某台机器、某个编译选项下你可能看到一个负数，换个选项可能就不是了。

<Callout variant="warning" title="未定义行为">
这是 C 里一个重要的概念，之后几课会反复出现：数组越界、使用已经释放的内存，都属于未定义行为。它的意思不是「会报错」，而是「什么都可能发生」，包括看起来一切正常。程序里只要有一处未定义行为，它的结果就不可信。
</Callout>

写程序时的做法：先想清楚一个数最大会到多少，选一个装得下的类型。拿不准就用 `long`。

<KeyTakeaway>
C 的每个变量都有类型，类型决定它在内存里占几个字节、能装多大的数。整数除以整数还是整数；`char` 是一个字节的小整数。无符号整数装不下时绕回去，结果是对「最大值加 1」取余；有符号整数溢出是未定义行为。分支和循环的道理与 Python 相同，写法换成圆括号加花括号。很多错误编译器看得出来，但只在加了 `-Wall` 时才说。
</KeyTakeaway>
