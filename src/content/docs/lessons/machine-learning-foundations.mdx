## 引导问题：机器怎样从例子中形成判断

先看一个你天天都在用的东西：垃圾邮件过滤。如果让你写程序判断一封邮件是不是垃圾邮件，最直接的办法是列条件：

```text
出现“免费领取”      → 风险分 +3
发件域名位于黑名单  → 风险分 +5
风险分达到 5         → 拦截
```

这个办法能用，但有明显的短板：骗子的措辞每天都在变，你得不停手动补规则，而且永远不知道还漏了什么。

换一条路。把过去几年用户标记过的几十万封邮件收集起来，每封都带着「是垃圾」或「不是垃圾」的答案。让程序自己从这批邮件里找规律，找出来的规律用来判断明天收到的新邮件。这条路就是机器学习：人不直接写规则，人提供例子，规律由程序从例子里学出来。

```text
现实目标
  → 数据与标签（收集带答案的例子）
  → 特征表示（把邮件变成数字）
  → 模型与损失（可调整的规律 + 衡量好坏的标准）
  → 参数优化（按标准自动调整）
  → 独立评估（用没见过的例子考试）
  → 部署监控（上线后持续观察）
```

规则系统的知识直接写在条件里，机器学习系统的知识藏在训练数据、特征表示、模型结构和参数里。两类系统都需要人定义目标、边界、错误代价和验收标准。本课沿这条线展开：先把任务说清楚，再看数据，然后是模型怎样预测、误差怎样度量、参数怎样调整，最后是怎样确认模型真的学会了。

## 一、先把现实问题定义成学习问题

### 1. 先分清三个词：AI、机器学习与深度学习

新闻里这三个词经常混着用，课程里要分开。**人工智能（AI）** 是最大的那个圈：让计算机完成需要智能的任务，包括感知、预测、生成、规划和决策，规则系统也算 AI 的一种实现。**机器学习（ML）** 是实现 AI 的一条路：不从例子学规律，程序就没有自动变好的机制；机器学习让参数随数据调整，模型因此能处理新输入。**深度学习（DL）** 是机器学习的一个分支：用多层神经网络学习逐层表示，是下一课的主题。（来源：[What is Machine Learning?](#source-google-intro-ml)、[Machine Learning Glossary](#source-google-ml-glossary)、[Dive into Deep Learning](#source-d2l-index)）

### 2. 什么是学习问题：把它当成一场开卷考试

「学习」这个词放在计算机上，含义比日常用法窄得多，也具体得多。计算机的学习指的是：**给程序一批带标准答案的例子，程序调整内部的数字，让它在没见过的例子上也能给出答案。** 这样一个任务就叫一个学习问题。

对应你熟悉的考试场景：做过的练习题是**训练数据**，题目附的标准答案是**标签**，练出来的解题能力是**模型**，高考考卷上的新题是**新输入**。会学习的标志是考卷上的新题也能做对，而不只是把练习题背下来。

把一个现实任务写成学习问题，至少要交代五件事。以垃圾邮件为例：

只说「训练一个 AI」会留下大量未定义项，至少这些问题没有答案：

- 给谁用：全部用户，还是某个地区的新用户？
- 答案什么时候定：发送瞬间，还是用户事后标记？
- 允许看哪些信息：只有正文，还是连发件历史也算？
- 拦错的代价是什么：漏放一封垃圾邮件，还是拦下一封录取通知？

这些选择都会改变最终方案。定义学习问题时把五个要件写清楚，后面的每一步才有依据。

### 3. 参数和超参数：谁被学习，谁被设置

模型里有两类数字，来源完全不同，这个区分会贯穿整门课。

**参数**是模型自己学出来的数字，比如权重 `w` 和偏置 `b`。类比练习：做题练出的解题手感没人能直接给你，它是在反复对照答案、不断修正的过程中形成的，参数就是程序版的「手感」，由训练过程自动调整。

**超参数**是训练开始前由人设定的开关和档位，程序不自动学它们。类比课程安排：每次练习做几道题、多久考一次模拟卷，这些是老师事先定的；定得不合适，同样的努力效果差很多。两个最常见的超参数：

- **学习率**：每次调整参数的步子大小，下一节会看到它设大设小分别出什么问题。
- **批量大小**：每批看多少道题再总结一次，看得少改得勤但容易慌，看得多改得稳但费时间。

```text
输入 x + 参数 θ ──模型 f──> 预测 ŷ
训练：根据目标函数更新 θ（参数被学习）
推理：固定 θ，对新输入计算 ŷ
```

优化器在训练中还可能保存动量等中间量，这些属于训练过程的内部状态。

训练阶段更新参数；部署后普通推理使用固定参数计算输出。微调和在线学习会启动新的训练过程，形成新的参数版本。

### 4. 任务要输出什么，决定用什么目标函数

- **回归**预测连续数值，例如价格、时长和温度。
- **二分类**预测一个事件的概率，例如欺诈概率。
- **多分类**从互斥类别中选择，例如数字 `0–9`。
- **多标签分类**允许多个标签同时成立，例如“道路”“车辆”“行人”。
- **排序**比较候选项的相对顺序，例如搜索结果和推荐列表。

任务类型决定输出层、损失函数、阈值和评估指标。分类概率经过阈值才形成业务动作，阈值由误报与漏报代价决定。

## 三、模型怎样预测，误差怎样度量

前面说学习是「按标准自动调整参数」。这一节把这个标准造出来：先看最简单的预测模型，再给它配一个衡量好坏的数字。整节课最核心的公式都在这里，每个公式都先讲它解决什么问题。

### 1. 从猜价格开始：一条直线就是一个模型

一批房屋成交记录：

<DataTable
  caption="面积与成交价（示意数据）"
  headers={["面积（m²）", "成交价（万元）"]}
  rows={[
    ["50", "205"],
    ["68", "262"],
    ["85", "334"],
    ["102", "401"],
  ]}
/>

看着这批数据，你会猜测价格和面积大致是直线关系：面积每多一平米，价格涨一个固定的数。把猜测写成式子：

```text
ŷ = wx + b
```

`x` 是输入（面积），`w` 是每平米涨多少，`b` 是起点，`ŷ` 是预测。这就是**线性回归**，「模型」就是这条直线，`w` 和 `b` 就是它的**参数**。所谓学习，就是从「随手画一条」开始，自动调整 `w` 和 `b`，直到这条线尽量贴合数据点。

接着要回答：怎样算「贴合」？给每个数据点量一下竖直方向的差距：预测 210 万、实际 205 万，差 5 万；预测 240 万、实际 334 万，差负 94 万。差距有正有负，直接加起来会互相抵消，所以先平方再平均。这就是**均方误差（MSE）**，它把整批数据上的误差压成一个数字，这个数字就是「损失」：

```text
MSE = (1/N) Σ(ŷᵢ - yᵢ)²
```

损失越小说明这条线越贴合。平方还有第二个作用：差 94 万的点比差 5 万的点受罚重得多，大错误被重点惩罚。（来源：[Linear regression: Loss](#source-google-linear-loss)）

<LinearFitPlayground client:visible motionLevel="explanatory" />

亲手拖一拖就能体会到两件事：参数（`w` 和 `b`）决定直线位置，损失（MSE）量化贴合程度；而且随手调很难凑到最优组合，这正是下一节「让程序自动调」的动机。

### 2. 从「是不是垃圾邮件」开始：把分数压成概率

预测价格时输出是一个数，多大都行。判断垃圾邮件时，你想要的输出是「是垃圾邮件的可能性」，必须是 0 到 1 之间的数，0.9 表示很有把握是，0.1 表示多半不是。

线性模型的输出是任意大小的数，比如 8.3 或者 -5，直接当概率用不行。需要一个函数把任意数压进 0 到 1：**sigmoid** 就是这个函数。

```text
z = wᵀx + b                ← 模型先算出一个分数，这个分数叫 logit
p(y = 1 | x) = σ(z) = 1 / (1 + e⁻ᶻ)   ← sigmoid 把分数压成概率
```

sigmoid 把任意实数映射到 `0` 与 `1` 之间。`z = 0` 时概率为 `0.5`；`z` 增大时概率接近 `1`。Google 的逻辑回归课程用相同链路解释线性分数、sigmoid 和概率。（来源：[Calculating a probability with the sigmoid function](#source-google-logistic-sigmoid)）

模型输出概率之后，还差一个「衡量猜得好不好」的数字，也就是分类版的损失。这里的要求比直觉更严格一点：不只是猜错要罚，**错得越自信罚得越重**。模型说 0.9 是垃圾而实际真是垃圾，小罚；模型说 0.1 是垃圾而实际是垃圾，重罚。实现这个效果的函数叫**二元交叉熵**：

```text
BCE = -[y log(p) + (1-y) log(1-p)]
```

代入两个具体数字感受惩罚力度的差别。当真实标签 `y = 1`：

```text
模型给 p = 0.8  → 损失 -log(0.8) ≈ 0.223
模型给 p = 0.1  → 损失 -log(0.1) ≈ 2.303
```

同样的错误方向，自信程度不同，损失差十倍。逻辑回归使用 log loss，并通常配合正则化控制参数复杂度。（来源：[Logistic regression: Loss and regularization](#source-google-logistic-loss)）

### 3. 从「是哪个数字」开始：一组分数变一组概率

再进一步：识别手写数字，候选是 0 到 9 共十个类。模型对每个类都算一个 logit 分数，但你要的输出是「每个类的可能性」，而且十个可能性加起来应该等于 1。

**softmax** 做的就是这件事：把一组分数变成一组和为 1 的概率，分数越高概率越大。它就是二分类 sigmoid 的多分类版本。

```text
p(class = k) = exp(zₖ) / Σⱼ exp(zⱼ)
```

交叉熵同样升级为多分类版本：只看真实类别分到的概率，概率越低罚得越重，直觉与上一节完全一致。

```text
CE = -log(p(真实类别))
```

互斥类别用 softmax；多标签任务（一张图同时有“道路”“车辆”）对每个标签独立使用 sigmoid。

### 4. 树模型与集成：表格数据的另一条主线

前面三种模型都把输入写成函数、用梯度下降拟合。决策树走的是另一条路：对特征提一系列问题（「金额 > 1000 吗」），把样本递归划进更纯的子组，叶子的多数类别就是预测。树的学习目标不是损失函数的梯度，而是每次划分带来的不纯度下降，因此能直接处理数值与类别特征混合的表格，也更容易向非技术人员解释每一次判断。

单棵树容易过拟合，集成学习把多棵树组合起来。scikit-learn 把两类组合方式讲得很直接：**随机森林**并行训练多棵深树——每棵树用有放回抽样的数据子集、每次分裂只看随机特征子集，让各棵树的预测误差彼此解耦，最后取平均，方差随之下降；**梯度提升树（GBDT）**串行添加浅树——每棵新树拟合此前全部树的负梯度，等价于在函数空间里做梯度下降，逐步降低偏差。（来源：[Ensembles: Gradient boosting, random forests, bagging, voting, stacking](#source-sklearn-ensemble)）

在结构化表格任务上，树模型及其集成通常是首选基线：特征无需归一化、对单调变换不敏感、天然建模非线性切分。本课的垃圾邮件、欺诈检测示例都属于这一类场景；图像、文本这类原始信号则仍以神经网络为主。

### 5. 损失、指标和业务目标不在一层

损失是训练时自动优化用的，但它本身不是业务目标。垃圾邮件系统的损失下降了，用户关心的是漏拦截和误拦截；两者之间需要明确的换算。

### 6. 拟合误差的同时还要控制复杂度

训练常写成：

```text
J(θ) = (1/N) Σ L(fθ(xᵢ), yᵢ) + λΩ(θ)
```

第一项是训练样本上的平均损失，第二项是正则化。`λ` 控制数据拟合与复杂度约束的相对权重。L2 正则化惩罚较大的权重；早停根据验证曲线限制训练步数。（来源：[L2 regularization](#source-google-l2-regularization)）

## 四、优化：误差怎样变成参数更新

有了损失这个数字，学习就变成一个具体问题：调整参数，让损失尽量小。程序不知道最优参数在哪，只能从随机的初始值出发一步步改，这一节讲「每一步怎么走」。

### 1. 梯度：当前位置最陡的方向

想象蒙着眼睛下山：看不见全貌，但脚下的坡向能感觉到。合理的走法是每一步都沿脚下最陡的下坡方向迈一小步，走一步再看一次坡向。损失就是海拔，参数就是位置，**梯度**就是脚下最陡的上坡方向，学习算法沿它的反方向走。

<LossLandscape />

上图是两个权重的情形。为了把一步算到每个数字，先用单参数（一条曲线）走一遍。取一个样本 `x = 2`、`y = 4`，模型为 `ŷ = wx`，损失为平方误差。初始 `w = 0.5`：

```text
前向：ŷ = 0.5 × 2 = 1
损失：L = (1 - 4)² = 9
梯度：dL/dw = 2(ŷ - y)x = -12
更新：w ← w - η(dL/dw)
```

梯度是负数，说明增大 `w` 能降低损失。学习率 `η = 0.05` 时，新权重为 `1.1`，复算损失得到 `3.24`，确实变小了。反复执行这四行就是**梯度下降**。（来源：[Linear regression: Gradient descent](#source-google-linear-gradient)）

单参数会算一步之后，回到上面那张等高线图——把它变成可以亲手走一遍的模拟器。模型换成 `ŷ = w₁x₁ + w₂x₂` 配两个样本，损失面就是一张真正的椭圆「山地」，谷底在两个残差同时为 0 的地方：

<NeuralNetworkSimulator client:visible motionLevel="simulation" />

动画同时显示两个残差、损失和梯度向量，轨迹一步步踩在等高线图上。学习率较小时每步稳定下山；拉到 0.055 以上，步子开始越过谷底轴线、在陡谷两侧来回振荡但仍能收敛；拉过 0.11（这张损失面的稳定上限），损失每步放大、轨迹发散飞出画面。稳定上限由损失面的最陡曲率决定，换一张面，阈值就变。

### 2. 多参数与 mini-batch 使用同一更新规则

真实模型有百万级参数，但更新规则不变。对参数向量 `θ` 和大小为 `B` 的批次：

```text
g = (1/B) Σᵢ ∇θ L(fθ(xᵢ), yᵢ)
θₜ₊₁ = θₜ - ηg
```

完整批量梯度稳定但计算开销大；单样本梯度噪声高；mini-batch 在并行效率和梯度波动之间取得常用折中。批量大小改变梯度统计和内存消耗，也会影响学习率选择。

## 五、泛化：训练分数不等于会做题

一个必须直面的问题：把练习题做满分的学生，高考不一定考得好。模型也一样：训练数据上的损失很低，只说明它「背」这批数据背得好；真正要的是没见过的新数据上表现也稳定，这个性质叫**泛化**。判断泛化靠一次「合规的考试」，这一节讲考试怎么组织。

### 1. 训练集、验证集和测试集各有职责

### 2. 欠拟合、高方差与分布差异产生不同信号

Stanford CS229 的偏差与方差分析用训练误差、开发误差和可达到误差定位改进方向。该诊断依赖统一的数据分布和可靠评估集。（来源：[Bias-Variance Analysis](#source-cs229-bias-variance)）

```text
欠拟合：训练损失高，验证损失也高        ← 练习题都做不好
合适区间：两条曲线同步下降，验证损失趋于稳定
过拟合：训练损失继续下降，验证损失开始上升  ← 练习越刷越好，模拟卷越考越差
```

这三种状态可以亲手制造出来。回到第三节的房价数据，这次多给几户、并留出 4 户当「考试」：拖动多项式阶数，1 阶时曲线太直、两边误差都大（欠拟合）；3 阶左右训练与考试误差同步走低（合适）；拉到 7 阶，曲线硬穿每一个训练点，训练误差趋近 0，考试误差却飙升（过拟合）：

代表性不足的数据和过强的模型容量都会造成过拟合。常见控制手段包括增加代表性数据、限制容量、L2 正则化、Dropout、数据增强和早停。（来源：[Overfitting](#source-google-overfitting)、[Dropout](#source-d2l-dropout)、[Image Augmentation](#source-d2l-image-augmentation)）

### 3. 泛化依赖切分方式和分布假设

随机切分隐含样本近似独立同分布且分布稳定的假设。真实任务常需要更贴近部署的切分：

- 时间预测按时间先后切分，使验证数据来自训练数据之后。
- 同一患者、用户、设备或文档组的记录放在同一侧。
- 地域部署保留目标城市或区域作为外部测试。
- 重复样本和近重复样本在切分前按实体去重。

经典 K-fold 交叉验证适合近似独立同分布的数据。时间序列需要时间顺序切分，群组数据需要 GroupKFold 等按组方法。交叉验证支持模型选择与稳定性估计，最终测试集继续保持独立。（来源：[Cross-validation: evaluating estimator performance](#source-sklearn-cross-validation)、[Splits and data leakage](#source-aws-splits-leakage)）

### 4. 数据泄漏会制造过于乐观的分数

考试泄题会推高分数，数据泄漏同理：测试侧的信息以任何方式进入训练过程，都会让分数虚高。

```text
泄漏路径：全体数据 → 计算均值、词表或特征选择 → 再切分
独立路径：先切分 → 训练集 fit → 验证/测试集 transform
```

scikit-learn 要求预处理器只在训练集上 `fit`，测试数据只使用已经学好的转换。Pipeline 能把预处理和模型封装进同一交叉验证流程。（来源：[Common pitfalls and recommended practices](#source-sklearn-data-leakage)）

标签泄漏还可能来自时间。预测贷款违约时使用“催收次数”，而催收发生在违约之后，这个字段在历史数据中与标签高度相关，真实预测时却无法获得。

### 5. 指标必须匹配错误代价

`1,000` 个样本中只有 `10` 个欺诈样本。模型全部预测为正常时，Accuracy 为 `99%`，欺诈 Recall 为 `0%`。类别失衡时，准确率会掩盖少数类失败。（来源：[Accuracy, precision, and recall](#source-google-classification-metrics)）

scikit-learn 的评估指南按任务提供多种指标，并支持交叉验证中的多指标评估；概率校准需要独立数据或交叉验证避免偏置。（来源：[Metrics and scoring](#source-sklearn-model-evaluation)、[Probability calibration](#source-sklearn-calibration)）

发现少数类被掩盖后，有三类对症手段，可以叠加使用：

1. **类别权重：** 训练时给少数类的损失乘上更大权重。scikit-learn 的 `class_weight='balanced'` 直接按频率反比设定权重 `n_samples / (n_classes × 各类样本数)`，让模型不再偏向多数类。（来源：[LogisticRegression class_weight](#source-sklearn-class-weight)）
2. **重采样：** 对少数类过采样或对多数类欠采样，改变训练分布；重采样只作用于训练集，验证与测试集必须保持真实分布，否则指标再次失真。
3. **阈值调整：** 分类阈值不必是 0.5。欺诈场景宁可多花人力复查，把阈值向提高 Recall 的方向移动，用 PR 曲线按业务代价选点。

三者的共同前提是先换指标：类别失衡时用 PR-AUC 与分场景 Recall 代替 Accuracy 做主指标，否则任何手段的效果都看不出来。

可信报告至少包含简单基线、数据版本、切分方法、样本量、指标与阈值、关键切片和多次运行波动。测试集分数的有效数字需要与样本量和不确定性匹配。

## 常见误解与能力边界

- **训练和推理：** 训练更新参数，推理使用固定参数计算输出。
- **参数和超参数：** 参数由优化器更新，超参数由配置、搜索或调度过程确定。
- **损失和业务结果：** 损失产生梯度，离线指标、业务指标和硬约束共同判断系统价值。
- **概率和决策：** 概率经过阈值形成动作，概率质量还需要校准检查。
- **训练分数和部署表现：** 泛化、分布变化、鲁棒性和错误代价需要独立评估。
- **预处理和切分：** 均值、词表、特征选择和去重都只能从训练侧学习。

本课的模型由线性分数和一个阈值构成，决策边界是一条直线。XOR 四个点、图像边缘和长距离指代关系需要可弯曲的边界，多层神经网络提供这条路径。下一课《神经网络：从神经元到架构》在同样的训练闭环上加入隐藏层、反向传播和四类架构。

<KeyTakeaway>
记住本课的两幅画：**损失面上的下山轨迹**——蒙眼走坡，梯度指反方向，步子（学习率）过猛会振荡甚至发散；**训练与考试误差的分叉**——阶数拉过头，训练误差趋近 0 而考试误差飙升，这就是过拟合的样子。数据决定能学到什么，切分与独立评估决定「学会」二字是否成立。
</KeyTakeaway>
