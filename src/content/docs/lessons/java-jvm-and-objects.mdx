## 引导问题：编译好的程序能不能拿到别的系统上运行

第 19 课用 gcc 编译出来的 `hello`，拷到 Windows 上运行不了：它是给 Linux 和这颗 CPU 准备的机器码。Python 和 PHP 没有这个问题，但每次运行都要从源码开始解释。

Java 走了中间一条路：先编译，但编译成一种不依赖操作系统的指令，再由每个系统上的 Java 虚拟机去执行。这节课先看清这条路，再用 Java 写一点代码。

### 数组越界：Java 会拦下来

<CodeFile file="labs/java-jvm-and-objects/Crash.java" mark="4" note="循环条件写成了 <=，最后一次 i 等于 3。" />

<TerminalSession
  title="越界访问"
  steps={[
    { cmd: 'javac Crash.java' },
    { cmd: 'java Crash', out: '90\n75\n88\nException in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3\n\tat Crash.main(Crash.java:5)' },
    { cmd: 'echo $?', out: '1' },
  ]}
/>

第 22 课里，C 程序越界读到的是数组后面内存里碰巧有的东西，程序还照常往下跑。Java 每次访问数组都检查下标，越界就**抛出异常**：停止正常的执行，打印异常的类型、原因和发生位置（`Crash.java` 第 5 行，在 `main` 方法里）。读 Java 报错，先看第一行说了什么，再看 `at` 开头的那几行指向哪里。（来源：[ArrayIndexOutOfBoundsException](#source-jv-aioobe)、[What Is an Exception?](#source-jv-exceptions)）

第三行是 `alice(73) true`。`Student c = a;` 没有复制出一个新学生，只是让 `c` 也指向 `a` 指向的那个对象，所以通过 `c` 加的 10 分，从 `a` 也看得到；`a == c` 比较的是两个变量是不是指向同一个对象，结果是 true。这和第 8 课 Python 的列表、第 32 课 PHP 的对象一样。真正创建对象的只有 `new`。（来源：[Creating and Using Objects](#source-jv-objects)、[JLS 15.21.3](#source-jv-jls15)）

`ArrayList<Student>` 是一个能自动变长的列表，尖括号里写元素的类型；`for (Student s : list)` 依次取出每个元素，相当于 PHP 的 foreach。（来源：[ArrayList](#source-jv-arraylist)）

<KeyTakeaway>
JDK 里的 javac 把 .java 编译成字节码 .class，java 启动 Java 虚拟机执行它；字节码不依赖操作系统，同一个 .class 装好 Java 就能运行。Java 的类型、数组、循环、方法和 C 很像，但类型错误在编译时就报出来，数组越界会抛出异常而不是悄悄读错内存。类由 private 字段、构造方法和方法组成，new 创建对象；把一个对象变量赋给另一个变量，两者指向同一个对象。
</KeyTakeaway>
