## 引导问题：三页可以手敲，三百页呢

上一课的作业让你依次请求 `/api/items?page=1`、`page=2`、`page=3`，再数一共有多少项。三页，敲三条命令，不算麻烦。

如果有三百页，或者你事先根本不知道有几页呢？

这类「把同一件事重复很多遍，每次只改一点点」的工作，正是第 6 课的循环擅长的。缺的只是一样东西：让 Python 能发出 HTTP 请求。

### 3. JSON：给程序读的正文

练习站的 `/api/items` 返回的不是给人看的句子，而是一种叫 **JSON** 的格式。它的写法和 Python 的字典、列表几乎一样，专门用来在程序之间传数据。

<TerminalSession
  environment="PYTHON 交互模式"
  prompt=">>>"
  title="把正文变成字典"
  steps={[
    { cmd: 'import requests' },
    { cmd: 'r = requests.get("http://127.0.0.1:8000/api/items", params={"page": 3})' },
    { cmd: 'r.text', out: '\'{"page": 3, "total": 12, "items": [{"id": 11, "name": "item-11", "price": 55}, {"id": 12, "name": "item-12", "price": 60}]}\\n\'', note: '正文是一个字符串。它长得像字典，但现在还只是一串字符。' },
    { cmd: 'data = r.json()', note: '按 JSON 的规则解析这串字符。' },
    { cmd: 'type(data)', out: "<class 'dict'>", note: '现在是真正的字典了，第 8 课学的操作都能用。' },
    { cmd: 'data["total"]', out: '12' },

    { cmd: 'data["items"][0]["name"]', out: "'item-11'", note: '一层一层往里取：items 列表的第 0 项的 name。' },

## 三、socket：requests 底下那一层

### 1. 自己把请求写出来

`requests` 很方便，但它没有任何魔法。第 13 课你用 `nc` 手敲过请求，证明了请求只是一段文字。Python 的 `socket` 模块做的就是 `nc` 那件事：建立一条 TCP 连接，然后收发字节。

### 2. requests 替你做了什么

平时写脚本用 `requests`。需要 `socket` 的场合有两种：对方说的不是 HTTP，而是别的协议；或者你要发出一个格式故意不合常规的请求，而 `requests` 不让你那样写。这两种情况下学期都会遇到。

<Callout variant="warning" title="脚本的速度和你的责任">
脚本一秒钟能发出几百个请求。对自己的练习站怎么跑都行。对别人的网站，未经允许的大量自动请求会给对方造成负担，可能违反对方的使用条款，严重时违法。本学期的脚本只对 `127.0.0.1` 和社团提供的练习环境运行。
</Callout>

<KeyTakeaway>
`requests` 让 Python 成为 HTTP 客户端：`get` 和 `post` 发请求，`params` 和 `data` 传参数，响应的状态码、头部、正文都是对象的属性，`Session` 负责保管 Cookie。配合循环和 `try`，就能把重复的请求交给脚本。它底下仍然是一条 TCP 连接上来回的文字，用 `socket` 可以把这段文字亲手写出来。
</KeyTakeaway>
