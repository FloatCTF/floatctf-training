## 引导问题：你现在在哪

图形界面里，文件管理器的窗口标题和地址栏一直在告诉你「现在打开的是哪个文件夹」。命令行里没有窗口，但同样有一个「当前所在的文件夹」，每条命令都从这里出发找文件。

打开 Kali 的终端，输入 `pwd` 回车：

<TerminalSession
  title="问终端：我在哪"
  steps={[
    { cmd: 'pwd', out: '/home/kali', note: 'pwd 是 print working directory 的缩写，打印当前所在的目录。刚打开终端时，你在自己的家目录里。' },
  ]}
/>

这一课的所有内容都围绕两个问题：我在哪，我要操作的东西在哪。

## 一、提示符、命令与路径

### 1. 读懂提示符

终端等你输入时显示的那段文字叫**提示符**（prompt）。Kali 的提示符有两行：

```text
┌──(kali㉿kali)-[~]
└─$
```

<DataTable
  caption="Kali 提示符的每一部分"
  headers={["片段", "含义", "什么时候会变"]}
  rows={[
    ["kali㉿kali", "㉿ 前面是当前用户名，后面是这台机器的名字", "换用户登录，或连到别的机器时"],
    ["[~]", "当前所在的目录。~ 是家目录的简写", "每次 cd 之后"],
    ["$", "当前是普通用户，终端在等你输入", "以 root 身份操作时变成 #"],
  ]}
  columnRatios={[1, 2, 1.6]}
/>

替你读入这一行、找到对应程序并执行的那个程序叫 **shell**。Kali 默认的 shell 是 zsh。（来源：[Kali Linux 2020.4 Release](#source-kali-2020-4-release)、[Missing Semester](#source-missing-semester-shell)）

本站的示例把提示符简写成一个 `$`。抄命令时只抄 `$` 后面的部分。

### 2. 一条命令的三个部分

```text
ls -l /etc
```

- `ls` 是**命令名**：要运行哪个程序。
- `-l` 是**选项**：调整这个程序的行为，通常以 `-` 开头。
- `/etc` 是**参数**：操作的对象。

三部分之间用空格隔开，所以空格本身有意义：`ls-l` 和 `ls -l` 是两回事。命令区分大小写，`Cat` 和 `cat` 也是两回事。

### 3. 目录树和两种路径

Linux 的所有文件挂在一棵树上，树根写作 `/`。从根出发一级一级写到目标，各级之间用 `/` 隔开，这样写出来的位置叫**路径**。

<TerminalSession
  title="看一眼树根下面有什么"
  steps={[
    {
      cmd: 'ls /',
      out: 'bin   dev  home  lib64  mnt  proc  run   srv  tmp  var\nboot  etc  lib   media  opt  root  sbin  sys  usr',
      note: '你的虚拟机里会多出几项，属正常。',
    },
  ]}
/>

<DataTable
  caption="先认识五个目录"
  headers={["目录", "放什么"]}
  rows={[
    ["/home", "普通用户的家目录。你的是 /home/kali"],
    ["/etc", "这台机器的系统配置文件"],
    ["/tmp", "临时文件"],
    ["/bin", "所有用户都要用的基本命令，例如 ls、cat"],
    ["/root", "root 用户的家目录，普通用户进不去"],
  ]}
  columnRatios={[1, 3]}
/>

（来源：[Filesystem Hierarchy Standard 3.0](#source-fhs-3)）

路径有两种写法，区别只看开头：

- **绝对路径**以 `/` 开头，从树根写起。无论你在哪，它指向的都是同一个位置。
- **相对路径**不以 `/` 开头，从当前目录写起。你换了位置，它指向的地方就跟着变。

相对路径里有三个特殊写法：`.` 代表当前目录，`..` 代表上一级目录，`~` 代表你的家目录。（来源：[Missing Semester](#source-missing-semester-shell)、[zsh Manual](#source-zsh-expansion)）

## 二、建、看、复制、改名、删除

这一段跟着敲。每条命令敲完后，把你的输出和页面上的对一下。

### 1. 建一个练习目录

### 2. 建文件并查看

<TerminalSession
  title="写一个文件，再读出来"
  steps={[

    { cmd: 'ls -a', out: '.  ..  notes  web', note: '-a 连以 . 开头的名字也列出来。每个目录里都有 . 和 ..，分别指向它自己和它的上一级。' },

### 5. 删除

<Callout variant="danger" title="rm 没有回收站">
`rm` 删掉的文件不会进回收站，命令行里也没有撤销。敲回车之前，看清楚路径；用 `rm -r` 之前，先用 `ls` 看一眼那个目录里有什么。
</Callout>

<TerminalSession
  title="rm 删文件，rmdir 删空目录，rm -r 连目录带内容一起删"
  steps={[
    { cmd: 'rm web/home.txt' },
    { cmd: 'ls web', note: '什么都没打印，说明 web 已经空了。' },
    { cmd: 'rmdir web', note: 'rmdir 只能删空目录。' },
    { cmd: 'rm notes', out: "rm: cannot remove 'notes': Is a directory", note: 'rm 默认不删目录。' },
    { cmd: 'mkdir -p tmp/a/b', note: '-p 让 mkdir 把中间缺的目录一并建出来。' },
    { cmd: 'rm -r tmp', note: '-r 表示递归：把目录和里面的所有东西一起删掉。' },
    { cmd: 'ls', out: 'notes' },
  ]}
/>

## 三、自己查帮助、读报错

### 1. 三种查法

没人能记住所有命令的所有选项。会查比会背重要。

<TerminalSession
  title="从最短的说明到完整手册"
  steps={[
    { cmd: 'man -f cp', out: 'cp (1)               - copy files and directories', note: '一句话说明这个命令是干什么的。' },
    {
      cmd: 'ls --help | head -n 4',
      out: 'Usage: ls [OPTION]... [FILE]...\nList information about the FILEs (the current directory by default).\nSort entries alphabetically if none of -cftuvSUX nor --sort is specified.',
      note: '多数命令加 --help 会打印简短帮助。后面的 | head -n 4 只留前四行，| 的用法下一课讲。',
    },
  ]}
/>

完整的手册用 `man 命令名` 打开，例如 `man ls`。操作方式和 `less` 相同：方向键或空格翻页，输入 `/` 加关键词回车可以搜索，按 `q` 退出。（来源：[Missing Semester](#source-missing-semester-shell)）

### 3. 常见报错怎么读

报错的格式通常是「谁报的：对什么：出了什么问题」。先读冒号后面的最后一段。

<DataTable
  caption="本课最容易遇到的报错"
  headers={["你输入的", "终端的回答", "原因和处理"]}
  rows={[
    ["cat first.txt", "cat: first.txt: No such file or directory", "当前目录里没有这个文件。先 pwd 确认自己在哪，再 ls 看看文件到底在哪个目录。"],
    ["cd notes/first.txt", "cd: not a directory: notes/first.txt", "cd 只能进目录，first.txt 是文件。"],
    ["cat notes", "cat: notes: Is a directory", "cat 读的是文件，notes 是目录。想看目录里有什么用 ls。"],
    ["rm notes", "rm: cannot remove 'notes': Is a directory", "rm 默认不删目录。空目录用 rmdir，非空目录确认后用 rm -r。"],
    ["Cat notes/first.txt", "Command 'Cat' not found, did you mean: …", "命令区分大小写。Kali 会猜你想输入什么并列出候选，这里正确的是小写的 cat。"],
    ["htop", "Command 'htop' not found, but can be installed with: sudo apt install htop，然后问 Do you want to install it? (N/y)", "这个程序还没装。现在输入 n 回车跳过，装软件下一课讲。"],
  ]}
  columnRatios={[1, 1.7, 2.2]}
/>

边界：命令行不会替你检查「这样做是否合理」。路径写对了它就执行，包括删除。它只在做不到的时候报错。

<KeyTakeaway>
每条命令都从「当前目录」出发找文件。路径以 `/` 或 `~` 开头，指向的位置固定；其他写法都从当前目录算起，`..` 往上走一级。不确定时先 `pwd` 再 `ls`，不认识的命令先 `man`。
</KeyTakeaway>
