## 引导问题：上节课那一行是什么

上节课做 URL 编码时，照抄过这样一行：

```text
python3 -c "import urllib.parse; print(urllib.parse.quote('a b&c'))"
```

`python3` 是一个程序，叫 **Python 解释器**。它读入一段 Python 代码，逐句执行。`-c` 后面引号里的那段文字，就是交给它执行的代码。

把代码塞在一行引号里只适合临时用一下。这一课学另外两种更常用的方式，并且从这一行里最基础的部分讲起：值、类型和名字。

## 一、两种运行方式与四种类型

### 1. 交互模式：问一句，答一句

在终端里只输入 `python3` 回车，会看到版本信息和一个新的提示符 `>>>`。这是 Python 的**交互模式**：你输入一句，它立刻执行并显示结果。（来源：[Using the Python Interpreter](#source-py-interpreter)）

<TerminalSession
  title="把 Python 当计算器"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: '1 + 2', out: '3' },
    { cmd: '7 / 2', out: '3.5', note: '/ 是除法，结果总是带小数点。' },
    { cmd: '7 // 2', out: '3', note: '// 是整除：只要商的整数部分。' },
    { cmd: '7 % 2', out: '1', note: '% 取余数。' },
    { cmd: '2 ** 10', out: '1024', note: '** 是乘方。' },
    { cmd: '"ab" + "cd"', out: "'abcd'", note: '用引号括起来的是文字。+ 把两段文字接起来。' },
    { cmd: '"ha" * 3', out: "'hahaha'", note: '文字乘以整数是重复。' },
  ]}
/>

（来源：[An Informal Introduction to Python](#source-py-introduction)）

提示符是 `>>>` 时，你在和 Python 说话；提示符是 `$` 时，你在和 shell 说话。两边的语法互不相通，在 `>>>` 后面输入 `ls` 会报错。退出交互模式输入 `quit()` 回车，或按 `Ctrl` + `D`。

### 2. 四种基本类型

每个值都属于某种**类型**（type）。类型决定了这个值能做哪些运算。`type()` 可以查看一个值的类型：

<TerminalSession
  title="type() 看类型，int()、str()、float() 做转换"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: 'type(42)', out: "<class 'int'>" },
    { cmd: 'type(3.14)', out: "<class 'float'>" },
    { cmd: 'type("kali")', out: "<class 'str'>" },
    { cmd: 'type(True)', out: "<class 'bool'>" },
    { cmd: 'int("42") + 1', out: '43', note: 'int() 把文字 "42" 转成整数 42。' },
    { cmd: 'str(42) + "!"', out: "'42!'", note: 'str() 把整数转成文字。' },
    { cmd: 'float("3.5") * 2', out: '7.0' },
  ]}
/>

<DataTable
  caption="先记住这四种"
  headers={["类型", "名字", "例子", "说明"]}
  rows={[
    ["整数", "int", "42、-7、0", "没有位数上限"],
    ["浮点数", "float", "3.14、7.0", "带小数点的数。/ 的结果总是这种类型"],
    ["字符串", "str", "\"kali\"、'a b'", "一段文字。单引号和双引号效果相同"],

`"42"` 和 `42` 是两个不同的东西：前者是两个字符组成的文字，后者是一个数。上一课讲过，文字在计算机里是一串字节；类型就是告诉 Python 该把这些字节当成什么来用。

### 3. 脚本：把代码存进文件

交互模式里的代码关掉就没了。要反复运行的代码写进文件，这样的文件叫**脚本**，Python 脚本的扩展名是 `.py`。

<StepList title="写出并运行第一个脚本" steps={writeSteps} />

<CodeFile file="labs/python-variables-and-types/hello.py" />

<TerminalSession
  title="运行脚本"
  steps={[
    { cmd: 'cd ~/lab/python' },
    { cmd: 'python3 hello.py', out: 'hello, kali\n3', note: '解释器从第一行开始，一行一行往下执行。' },
  ]}
/>

`print()` 把括号里的值打印到屏幕上。交互模式会自动显示每个表达式的结果，脚本不会：脚本里只有写了 `print()` 的地方才有输出。

<Callout variant="warning" title="写代码时用英文输入状态">
代码里的引号、括号、冒号、逗号必须是英文的。中文输入法下打出的 `“`、`（`、`：` 是全角符号，Python 不认，会报 SyntaxError。写代码时保持英文输入状态；需要在引号里面写中文时再切过去，写完切回来。本学期的示例脚本为了省去来回切换，提示语都用英文。
</Callout>

## 二、变量、输入与输出

### 1. 变量是贴在值上的名字

`=` 的作用是**赋值**：先算出右边的值，再让左边的名字指向它。之后用这个名字，就是在用那个值。

<TerminalSession
  title="起名字，用名字"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: 'port = 8080', note: '赋值没有输出。' },
    { cmd: 'port', out: '8080' },
    { cmd: 'port + 1', out: '8081', note: 'port 本身没有变，这只是算了一个新值。' },
  ]}
/>

在 Python 里，值是放在内存里的**对象**，变量是指向对象的**名字**。这个区别在连续赋值时会显出来。把下面五行存成 `names.py`，先自己猜最后一行打印什么：

<CodeFile file="labs/python-variables-and-types/names.py" />

<CodeStepper
  client:visible
  trace={namesTrace}
  title="a = a + 1 之后，b 是多少"
  intro="圈号代表对象。两个名字后面的圈号相同，说明它们指向同一个对象。"
/>

<TerminalSession
  title="运行验证"
  steps={[
    { cmd: 'python3 names.py', out: '4 3 kali' },
  ]}
/>

第三行 `a = a + 1` 做了两件事：算出新对象 4，把名字 a 改贴到 4 上。名字 b 没有出现在等号左边，所以它指向的对象没有变。`=` 不是数学里的「相等」，它是一个动作。（来源：[Data model](#source-py-datamodel)、[Execution model](#source-py-executionmodel)）

变量名可以用字母、数字和下划线，不能以数字开头，区分大小写。（来源：[Lexical analysis](#source-py-lexical)）起名字的原则是让人一眼看出它装的是什么：`port`、`user_name` 比 `a`、`x1` 好。

### 2. input()：从键盘读入

<CodeFile file="labs/python-variables-and-types/age.py" />

<TerminalSession
  title="运行时输入名字和年龄"
  steps={[
    {
      cmd: 'python3 age.py',
      stdin: ['kali', '18'],
      out: 'name: kali\nage: 18\nkali, next year you will be 19',
      note: '程序在 name: 后面停下来等你输入，回车后继续。',
    },
  ]}
/>

三行代码里有三个新东西：

- `input("name: ")` 先打印括号里的提示，再等你输入一行，然后把你输入的内容作为**字符串**交回来。
- `int(...)` 把字符串转成整数。`input()` 交回来的永远是字符串，哪怕你输入的是数字；不转换就不能做加法。
- `f"..."` 是**格式化字符串**：引号前加一个 f，花括号里可以写变量名或算式，运行时会被替换成它的值。

（来源：[Built-in Functions](#source-py-functions)、[Input and Output](#source-py-inputoutput)）

<TerminalSession
  title="f-string 的花括号里可以放算式"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: 'name = "kali"' },
    { cmd: 'age = 18' },
    { cmd: 'f"{name} is {age}"', out: "'kali is 18'" },
    { cmd: 'f"{age + 1}"', out: "'19'" },
    { cmd: 'print(f"{name} is {age}")', out: 'kali is 18', note: '交互模式直接显示字符串时带引号，print() 打印时不带。' },
  ]}
/>

## 三、读懂三种报错

写程序的大部分时间在和报错打交道。Python 的报错信息很完整，读的顺序是**先看最后一行**。

### 1. 脚本报错：Traceback

`broken.py` 比 `age.py` 少了一个 `int()`：

<KeyTakeaway>
解释器一行一行执行代码。每个值都有类型，类型决定它能做什么运算；`input()` 读进来的永远是字符串。变量是指向对象的名字，`=` 让等号左边的名字改指向右边算出的对象，别的名字不受影响。报错从最后一行读起。
</KeyTakeaway>
