## 引导问题：那串字符，这次用 Python 解

第 4 课最后用一条管道解开了这串字符：

```text
NjY2YzYxNjc3YjY4NjU2YzZjNmY3ZA==
```

管道适合两三层固定的编码。层数一多，或者中间夹着一步自定义的运算（比如每个字节都和某个数做异或），命令行就不够用了。这一课结束时，你会用 Python 脚本解它，并且能对付带异或的版本。

## 一、字符串的常用操作

### 1. 切、拼、换、查

字符串是字符的序列，下标和切片的用法和列表完全相同。除此之外，它自带一批处理文本的方法：

<TerminalSession
  title="最常用的字符串方法"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: 's = "  Kali Linux  "' },
    { cmd: 's.strip()', out: "'Kali Linux'", note: 'strip 去掉两头的空白。读入的每一行末尾都带着换行，几乎总要先 strip。' },
    { cmd: 's.strip().lower()', out: "'kali linux'", note: '方法可以连着调用，从左到右依次执行。' },

    { cmd: '"-".join(["2026", "10", "01"])', out: "'2026-10-01'", note: 'join 反过来：用分隔符把列表里的字符串连起来。' },

字符串是不可变对象。上面每个方法都返回一个**新**字符串，原来的 `s` 没有变。想保留结果，要赋值：`s = s.strip()`。（来源：[Built-in Types](#source-py-stdtypes)）

## 二、str 与 bytes

### 1. 两种类型

第 4 课的结论是：文字要先变成字节，才能存进文件或发到网络上。Python 把这两个阶段分成两种类型：

- **str**：文字，由字符组成。你看到的、打印的、`input()` 读到的都是它。
- **bytes**：字节，由 0 到 255 的整数组成。文件里存的、网络上传的都是它。字面值写作 `b"..."`。

<TerminalSession
  title="encode：文字变字节；decode：字节变文字"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: 's = "中A"', note: '一个汉字加一个字母。用 Ctrl + 空格切到拼音打「中」，打完切回英文。' },
    { cmd: 's', out: "'中A'" },
    { cmd: 'len(s)', out: '2', note: '两个字符。' },
    { cmd: 'b = s.encode()', note: 'encode 按 UTF-8 把文字变成字节。' },
    { cmd: 'b', out: "b'\\xe4\\xb8\\xadA'", note: '显示 bytes 时，能当 ASCII 字符显示的字节显示成字符（A），其余显示成 \\x 加两位十六进制。' },
    { cmd: 'len(b)', out: '4', note: '四个字节：「中」占三个，A 占一个。' },
    { cmd: 'b[0]', out: '228', note: '取 bytes 的一个元素，得到的是整数。228 就是 0xe4。' },

    { cmd: 'type(b)', out: "<class 'bytes'>" },
  ]}
/>

<TerminalSession

（来源：[Built-in Exceptions](#source-py-exceptions)）

第二个报错在做题时很常见。它的意思是：这些字节不是 UTF-8 编码的文字。此时不要想办法「绕过」报错，应该回头想这些字节到底是什么，往往是还有一层没解，或者它本来就是二进制数据。用 `.hex()` 看一眼最稳妥。

### 3. 异或：最简单的「加密」

**异或**（XOR）是对二进制位的一种运算，写作 `^`：两位相同得 0，不同得 1。（来源：[Expressions](#source-py-expressions)）

<TerminalSession
  title="异或两次，回到原值"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: '65 ^ 32', out: '97', note: '65 是 01000001，32 是 00100000，逐位异或得 01100001，也就是 97。' },
    { cmd: 'chr(65 ^ 32)', out: "'a'", note: '大写 A 变成了小写 a。' },
    { cmd: '97 ^ 32', out: '65', note: '再异或一次同一个数，回到 65。' },
  ]}
/>

「同一个数异或两次会抵消」这个性质，让它成了最简单的加密方式：把每个字节都和一个密钥异或，得到密文；再异或一次，得到原文。

<CodeFile file="labs/python-strings-and-bytes/xor.py" mark="2" />

<TerminalSession
  title="同一个函数，既加密也解密"
  steps={[
    {
      cmd: 'python3 xor.py',
      out: "b'LFKMQREXW'\n4c464b4d5152455857\nb'flag{xor}'",
      note: '第一行是异或之后的字节，看不出原文；第三行对它再做一次同样的运算，原文回来了。',
    },
  ]}
/>

第 2 行 `bytes(b ^ key for b in data)` 的读法和列表推导式相同：依次取出 data 里的每个字节 b，算出 `b ^ key`，再把这一串结果组装成 bytes。

<Callout variant="warning" title="单字节异或没有安全性">
密钥只有一个字节，总共 256 种可能，写个循环全试一遍就能解开，课后作业第 4 题就是做这件事。它出现在这里，是因为大量入门题目用它，而且它是理解真正的加密算法的起点。
</Callout>

Base64 报错时，Traceback 里会出现一段标准库文件的路径，例如 `/usr/lib/python3.14/base64.py`。那不是你的代码，照旧先看最后一行，再往上找属于自己文件的那一段。

边界：`decode()` 默认按 UTF-8。遇到别的编码的数据（比如老旧中文系统常用的 GBK），需要写成 `decode("gbk")`。本学期的材料全部是 UTF-8。

<KeyTakeaway>
str 是文字，bytes 是字节，`encode()` 和 `decode()` 在两者之间转换，不能混用。十六进制、Base64、URL 编码在 Python 里各有一对函数。解多层编码时每一步都问一句：现在手里是 str 还是 bytes，下一步需要哪一种。
</KeyTakeaway>
