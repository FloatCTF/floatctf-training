## 引导问题：五个 IP，谁出现得最多

第 3 课用 `sort | uniq -c | sort -rn` 统计过日志里每个 IP 出现的次数。同样的事用 Python 怎么做？

先得有地方放这五个 IP，再得有地方记「每个 IP 出现了几次」。前者用**列表**，后者用**字典**。这一课结束时，你会用九行 Python 得到和那条管道相同的结论。

内容可以被修改的对象叫**可变对象**，列表和字典都是；整数、字符串、元组是**不可变对象**，只能造新的，不能改旧的。需要一份互不影响的列表时，用 `copy()`。（来源：[Data model](#source-py-datamodel)）

这条规则在函数里同样成立：把列表传给函数，函数里对它 append，函数外的列表也跟着变。

## 二、字典：按名字存取，并用它计数

### 1. 键和值

列表靠位置找元素。**字典**（dict）靠**键**（key）找**值**（value），写在花括号里，每一项是 `键: 值`。

### 2. 字典计数：一个固定写法

回到开头的问题。思路是：准备一个空字典，键是 IP，值是次数；把列表从头到尾过一遍，每遇到一个 IP，就把它的次数加 1。

<CodeFile file="labs/python-collections/count_ips.py" mark="4" />

<TerminalSession
  title="统计并找出最多的"
  steps={[
    {
      cmd: 'python3 count_ips.py',
      out: "{'192.0.2.10': 3, '198.51.100.7': 1, '203.0.113.5': 1}\n3 192.0.2.10\n1 198.51.100.7\n1 203.0.113.5\ntop: 192.0.2.10",
    },
  ]}
/>

逐行说明：

- 第 4 行是核心。`counts.get(ip, 0)` 取出这个 IP 目前的次数，第一次遇到时字典里还没有它，得到默认值 0。加 1 之后存回 `counts[ip]`。
- 第 6 行的 `counts.items()` 每次给出一对「键, 值」，分别绑到 `ip` 和 `n`。
- 第 8 行把字典的键按「对应的次数」从大到小排序。`key=counts.get` 的意思是：比较两个键时，比的是 `counts.get(键)` 的结果。排在最前面的 `top[0]` 就是出现最多的 IP。

「空字典、遍历、`get(键, 0) + 1`」这三步会反复用到：统计状态码、统计单词、统计字符出现的次数，都是同一个写法。

## 三、推导式、元组与两种越界

### 1. 列表推导式：一行写完「对每个元素做点什么」

<TerminalSession
  title="三种常见的推导式"
  environment="PYTHON 交互模式"
  prompt=">>>"
  steps={[
    { cmd: 'nums = [1, 2, 3, 4, 5, 6]' },
    { cmd: '[n * n for n in nums]', out: '[1, 4, 9, 16, 25, 36]', note: '对每个元素做运算，得到新列表。' },
    { cmd: '[n for n in nums if n % 2 == 0]', out: '[2, 4, 6]', note: '末尾加 if，只留下满足条件的元素。' },
    { cmd: '[len(w) for w in ["kali", "linux"]]', out: '[4, 5]' },
  ]}
/>

推导式的读法是从中间往两边：先看 `for n in nums`（从哪里取元素），再看最前面的表达式（对每个元素做什么），最后看末尾的 `if`（留下哪些）。它和下面四行等价：

```text
result = []
for n in nums:
    if n % 2 == 0:
        result.append(n)
```

（来源：[Data Structures](#source-py-datastructures)）

### 2. 元组，以及两种「取不到」

**元组**（tuple）写在圆括号里，用起来像列表，但创建后不能修改。它适合放一组固定的、成对出现的值，例如坐标，或者字典 `items()` 给出的每一对「键, 值」。

边界：`copy()` 只复制最外面这一层。列表里如果还装着列表，里层的列表仍然是共享的。这学期遇到的都是一层的列表，先知道有这回事。

<KeyTakeaway>
列表按位置存，字典按键存。它们是可变对象：两个名字指向同一个列表时，通过任何一个名字修改，另一个都看得到，要独立就 `copy()`。统计次数的固定写法是空字典加 `counts[k] = counts.get(k, 0) + 1`。
</KeyTakeaway>
