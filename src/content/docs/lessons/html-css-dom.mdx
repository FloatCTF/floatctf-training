## 引导问题：同一份响应，为什么长得不一样

第 14 课你用 `curl` 请求过练习站的首页，终端里打印出来的是一段夹着 `<h1>`、`<form>` 的文字。用浏览器打开同一个地址，看到的是一个大标题和一个能填的表单。

服务器给两者的内容一模一样。区别只在于：`curl` 把收到的文字原样打印，浏览器却读懂了这段文字，并且照着它画出了页面。

那段文字遵守的规矩叫 HTML。这一课学会读它，并且看清浏览器读完之后在内存里留下了什么。

有两个属性几乎所有元素都能用，后面要靠它们来找元素：

- `id`：给一个元素起一个独一无二的名字。一个页面里同一个 `id` 只应当出现一次。
- `class`：给元素贴一个或几个类别标记，多个之间用空格隔开。第 15 行的 `class="tool done"` 就贴了两个。

### 3. 嵌套成一棵树

元素可以放在别的元素里面。`li` 在 `ul` 里，`ul` 在 `body` 里，`body` 在 `html` 里。把这种「谁在谁里面」画出来，是一棵树：

```text
html
├── head
│   ├── meta
│   ├── title ── "Toolbox"
│   └── link
└── body
    ├── h1 ── "My Toolbox"
    ├── p
    │   └── a ── "Kali"
    ├── ul
    │   ├── li ── "curl"
    │   ├── li ── "nc"
    │   └── li ── "dig"
    └── form
        ├── input
        └── button ── "Search"
```

这和第 2 课的目录树是同一种结构：每个元素有一个上级，可以有若干下级。

## 二、DOM：浏览器内存里的树

### 2. 在控制台里读这棵树

    { cmd: 'document.querySelector("a").href', out: '"https://www.kali.org/"', note: '属性可以直接用点取。' },

括号里的 `"h1"`、`".done"`、`"#title"` 叫**选择器**，一共三种基本写法：直接写元素名，点加类名，井号加 id。第三节会看到，CSS 用的是同一套写法。（来源：[MDN: querySelector()](#source-mdn-queryselector)）

## 三、CSS 与表单

### 1. CSS：给选中的元素定样子

HTML 只说「这是标题、这是列表」，不管它长什么样。样子由 **CSS** 决定。一条 CSS 规则分两部分：先用选择器选出一批元素，再在花括号里写它们的样式。（来源：[MDN: What is CSS?](#source-mdn-css-what)）

回头读 `style.css`：

<DataTable
  caption="style.css 的五条规则"
  headers={["规则", "选择器的种类", "选中了谁", "效果"]}
  rows={[
    ["body { … }", "元素名", "body 元素", "无衬线字体，四周留白"],
    ["h1 { color: darkred; }", "元素名", "所有 h1", "暗红色"],
    [".tool { color: navy; }", "类", "所有 class 里有 tool 的元素，三个 li", "藏青色"],
    [".done { text-decoration: line-through; }", "类", "class 里有 done 的元素，最后一个 li", "删除线"],
    ["#title { border-bottom: … }", "id", "id 是 title 的那个元素", "下边框"],
  ]}
  columnRatios={[2, 0.9, 1.9, 1]}

（来源：[MDN: Basic CSS selectors](#source-mdn-css-selectors)）

最后一个 `li` 同时被 `.tool` 和 `.done` 两条规则选中，所以它既是藏青色又有删除线。

### 2. 表单：让用户发请求

第 14 课说过，表单是让用户填数据再提交给服务器的东西。看 `index.html` 的第 17 到 20 行：

```html
<form action="/index.html" method="get">
  <input name="q" placeholder="search">
  <button>Search</button>
</form>
```

<KeyTakeaway>
HTML 是一段用标签标出结构的文本。浏览器把它解析成一棵树，叫 DOM，再照着 DOM 画出页面；CSS 用选择器选中树上的元素并规定它们的样子。在开发者工具里可以看到这棵树，也可以用同样的选择器查找和修改它。改的只是自己浏览器内存里的 DOM，服务器上的文件不变，刷新即恢复。
