## 引导问题：为什么不直接在 Windows 上学

这个学期要做三类事：在命令行里操作文件和程序，写代码并运行，搭起有漏洞的网站再去分析它。这些事直接在自己的 Windows 上做会遇到三个麻烦。

- **弄坏了很难恢复。** 改错一个系统配置、删错一个目录，可能要重装系统。
- **工具和教程对不上。** 比赛环境、服务器和绝大多数安全工具运行在 Linux 上，命令和路径都和 Windows 不同。
- **实验对象不该放在日常环境里。** 故意留了漏洞的程序应当关在一个隔离的地方。

虚拟机同时解决这三件事：它是一台装在文件夹里的电脑，可以随时存档、随时恢复，里面装什么系统由你决定。

## 一、虚拟机是什么

### 1. 一台电脑里再开一台电脑

**虚拟机**（virtual machine）是用软件模拟出来的一台完整电脑。运行这个软件的真实电脑叫**宿主机**（host），装在虚拟机里的操作系统叫**客户机**（guest）。

<NestedLayers
  eyebrow="LAYERS / 谁运行在谁里面"

  layers={layers}
  note="越往里的层越容易重来：终端关掉重开，Kali 可以恢复快照，虚拟机整个删掉也只是删了一个文件夹。"
/>

客户机以为自己独占一台电脑。它看到的硬盘其实是宿主机上的几个大文件，它看到的网卡是虚拟机软件模拟的。这带来两个直接的好处：整台电脑可以复制、备份、删除；客户机里发生的事被挡在这几个文件里面。

Kali 官方制作这份虚拟机时给它分了 2 GB 内存和 80 GB 的磁盘上限；带桌面的 Kali 建议至少 2 GB 内存、20 GB 磁盘。（来源：[Kali inside VMware](#source-kali-vmware-guest)、[Installing Kali Linux](#source-kali-requirements)）

## 二、装好并开机

### 1. 安装 VMware Workstation Pro

<StepList title="安装 VMware Workstation Pro" steps={installSteps} />

多数电脑出厂时已经开启了硬件虚拟化。如果之后开机时 VMware 提示虚拟化功能被禁用，需要重启进入 UEFI（BIOS）设置把它打开，各品牌的入口不同，微软的说明页列出了主要厂商的操作文档。只改这一项，别动其他设置。（来源：[Enable Virtualization on Windows](#source-ms-enable-virtualization)）

### 2. 下载并校验 Kali 镜像

打开 kali.org 的 Get Kali 页面，进入 Virtual Machines，下载 VMware 的 64 位镜像。文件名形如 `kali-linux-2026.2-vmware-amd64.7z`，体积较大，校园网下载要一段时间。

下载完先确认文件完整。**哈希值**是根据文件内容算出来的一串字符，内容哪怕只差一个字节，算出来的结果也完全不同。把自己算的值和官网公布的值比对，就能知道文件有没有在下载中损坏或被替换。

在开始菜单里搜索 PowerShell（Windows 自带的命令行）并打开，先输入 `cd $HOME\Downloads` 进入下载目录（文件存在别处就换成对应的路径），再输入：

### 3. 解压并导入

<StepList title="把 Kali 导入 VMware" steps={importSteps} />

登录后看到的是 Kali 的桌面。鼠标点进虚拟机窗口后，键盘输入就进了 Kali；按 `Ctrl` + `Alt` 可以把鼠标还给 Windows。（来源：[Default Hot-Key Combinations](#source-vmware-hotkeys)）

### 4. 在终端里确认环境

在 Kali 桌面的面板上找到终端图标点开，或在应用菜单里搜索 terminal。**终端**是一个输入命令的窗口，本学期大部分操作都在这里完成。先输入四条命令，每输完一条按一次回车：

<TerminalSession
  title="确认自己是谁、在什么系统里"

      note: 'VERSION_ID 取决于镜像版本和更新状态：刚导入的镜像显示 2026.2，更新后会变成更新的数字。',
    },
  ]}
/>

你的终端里，命令前面显示的是两行提示符，形如 `┌──(kali㉿kali)-[~]` 和 `└─$`。它的读法留到下一课，现在只需要知道：看到 `$` 就表示终端在等你输入。本站的示例统一把提示符简写成一个 `$`。

Kali 默认以普通用户 kali 登录，日常操作没有管理员权限。需要管理员权限的命令在前面加 `sudo`，输入自己的密码后执行。（来源：[All about sudo](#source-kali-sudo)）

## 三、快照、网络、更新与输入法

### 1. 快照：出错之前的存档点

**快照**（snapshot）把虚拟机此刻的状态整个存下来。VMware 的定义是：快照包含虚拟机的内存内容、虚拟机设置和所有虚拟磁盘的状态，之后可以反复回到这个状态。（来源：[Taking Snapshots of Virtual Machines](#source-vmware-snapshots)）

两条使用习惯：

- 环境调好之后立刻拍一个，之后每次做没把握的操作前再拍一个。
- 恢复之前，把想留下的文件先拷到虚拟机外面。恢复会连同磁盘上的新文件一起撤销。

### 3. 第一次更新系统

Kali 的默认软件源是滚动更新的 `kali-rolling` 分支：里面的包持续更新，镜像只是某一时刻打包好的状态。所以装好后先更新一次。更新分两步，先刷新「有哪些新版本」的清单，再真正下载安装。

<TerminalSession
  title="刷新软件清单"
  steps={[
    {
      cmd: 'sudo apt update',
      out: '[sudo] password for kali: \nHit:1 http://http.kali.org/kali kali-rolling InRelease\n2 packages can be upgraded. Run \'apt list --upgradable\' to see them.',
      note: '输入密码时屏幕上什么都不显示，输完按回车即可。最后一行的数字因人而异，刚导入的镜像可升级的包会多得多。',
    },
  ]}
/>

然后执行 `sudo apt full-upgrade -y` 完成升级。`-y` 表示对「是否继续」自动回答「是」。屏幕会滚动很多行，等它回到 `$` 提示符就结束了。（来源：[Updating Kali](#source-kali-updating)）

### 4. 装中文输入法

Kali 的预装镜像能显示中文，但没有中文输入法。之后的课会在终端和代码里用到中文，这里一次装好。用的是 **Fcitx 5**：`fcitx5` 是输入法框架，`fcitx5-chinese-addons` 提供拼音等中文输入法。

<TerminalSession
  title="安装并设为默认"

  ]}
/>

<StepList title="让输入法生效" steps={inputMethodSteps} />

（来源：[Setup Fcitx 5](#source-fcitx-setup)、[Configtool (Fcitx 5)](#source-fcitx-configtool)）

<Callout variant="warning" title="敲命令和代码时切回英文">
中文输入状态下打出来的括号、引号、冒号、逗号是全角符号，长得和英文的很像，但命令和代码都不认。养成习惯：只在需要打汉字时切到拼音，打完立刻用 Ctrl + 空格切回英文。
</Callout>

更新和输入法都弄好之后，拍下第一个快照，命名为 `clean`。

<Callout variant="warning" title="Kali 里的工具用在哪">
Kali 预装了大量扫描和攻击工具。它们只能用在三类目标上：你自己的虚拟机、社团提供的靶场和比赛环境、得到书面授权的系统。对校园网和任何公网目标运行这些工具都是违规甚至违法的，本学期的课程也不需要这样做。
</Callout>

<KeyTakeaway>
虚拟机是一台装在文件夹里的电脑：VMware 负责模拟，Kali 是装在里面的系统，快照让它随时回到过去。环境搭好的标志是：能用 kali 登录，`whoami` 输出 kali，能切出中文输入法，有一个名为 clean 的快照。
</KeyTakeaway>
